# Archived MarkOS application

This tree preserves the original v0.2 Markdown/DuckDB application and tests imported through PR #5. Its CLI, API, watcher, PARA audit and knowledge models do not define the new product. No new-system features should be added here.

Build the independent event runtime proposed under `services/runtime/`, with no import/dependency on `markos`. Prior `markos.runtime` contract work in PR #6 is candidate review material, not an approved package boundary. Preserve history and existing behavior while retaining this archive.
