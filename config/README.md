# Configuration

Everything here is a synthetic example or a generated schema. Never commit real
credentials, DSNs or personal data. Secrets are referenced by name only.

| Path | Contents |
|---|---|
| `runtime/*.example.json` | Event, subscription, schedule and replay examples |
| `runtime/schemas/` | JSON schemas generated by `python -m markos_runtime.schemas --write`; CI fails if they drift |
| `runtime/lifecycle/` | Test-only service configs for the CI lifecycle harness |
| `runtime/control/` | Control-plane (API, web, chat, approvals, bills) examples |

Only `--config` selects a configuration file. `preflight-control` validates
control files without connecting or resolving secrets.
